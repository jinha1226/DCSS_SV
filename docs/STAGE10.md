# 10단계 바라치 마검사

> **지난 기록.** 끝난 10단계 기록이다. 공간술은 주술(`hexes`)로, 마법은 마법서 장착 방식([SKILL_TRAINING.md](SKILL_TRAINING.md))으로 바뀌었다. 문서 목록은 [README.md](README.md).

- 바라치 + 마검사 선택 가능. 장검 자동 근접 공격, 공간술은 버튼으로만 사용.
- 장검 스킬: 피해/공속 증가, 받아넘기기, 사거리 증가, 처치 시 공격 초기화.
- 공간술: 점멸(1단계, 전방 3칸), 위상막(2단계, 2초 무적). 무기 강화 주문은 없음.
- SUPERHOT: 공격 주문은 적 탭 조준, 보조 주문은 버튼을 누르면 1틱 진행하며 사용.
- 도약과 주문 버튼은 나란히 배치. 기존 던지기 버튼은 그대로 유지.
- 밸런스는 네 캐릭터를 만든 뒤 별도 단계에서 진행.
