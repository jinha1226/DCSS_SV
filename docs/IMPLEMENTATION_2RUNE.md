# DCSS_SV — 2룬/24층 일괄 구현 계획서

작성: 2026-10-12. **사용자 검토는 전 단계 완료 후 진행**한다. 단계 중 자동 검사는 허용하며 임의의 기능 축소·완료 주장 금지.

## 공통 불변 조건

- 자동 기본 공격, 수동 스킬·투척, 정지 시 시간 정지 유지.
- Dungeon 9 + Lair 3 + 3층 룬 브랜치 2개 + Vaults 3 + Zot 3 = 기본 24층. Temple 별도, Orc 등 선택. Depths 제거.
- Snake/Spider와 Swamp/Shoals는 각각 한 곳씩만 등장. 두 룬으로 Zot 진입.
- 브랜치 진입 순서 잠금 없음(난도와 저항으로 자연스럽게 유도). 성공 런 약 60분, 낮은 승률. 목표 시간은 측정 전 가설.
- DCSS 코드·볼트 파일 복제 금지. 몬스터 구성은 버전 명시 후 공식 자료와 위키를 교차검증.

## 1. 층별 시뮬레이션 시간 (01-floor-clock)

**구현 범위:** 층 진입 후 이동·전투·명시적 휴식에서만 시간이 흐르고 정지 관찰/선택창에서는 멈춘다. 기존 앱의 프레임 게이팅 확인 후 시간 소모 규칙을 한 곳에서 관리한다.

**완료 조건:** 180초 초기 제한, 초과 시 추적자 5초 간격. 추적자 경험치·처치회복·드롭 없음. 초과 경고 UI, 무한 생성 상한, 시드 재현 테스트.

**자동 검증:** 정지·회복·스킬 선택·초과 전후 경계값·XP 악용·몬스터 상한 테스트.

## 2. 층 상태 저장과 양방향 계단 (02-floor-state)

**구현 범위:** 층 키(branch,depth)별 grid, seen, monsters, groundItems, floorTime, nextBand, RNG 관련 상태를 보존. 계단 연결은 source/destination을 명시하고 재진입 시 기존 층 복원.

**완료 조건:** 계단 왕복으로 아이템·적·탐험 시야가 복제되지 않고 타이머가 초기화되지 않는다. 재방문 위치는 대응 계단.

**자동 검증:** 동일 시드 재현·왕복 100회·몬스터/아이템 복제·시간 보존 테스트.

## 3. 던전 그래프와 진행 (03-graph)

**구현 범위:** Dungeon 9, Lair 3, 룬 브랜치 각 3, Vaults 3, Zot 3, 선택 Orc 3. 매 런 Snake/Spider, Swamp/Shoals 중 각각 하나를 시드로 고정. Depths 제외.

**완료 조건:** 브랜치 입구는 난도만으로 진입 유도하고 하드 게이트는 Zot 2룬뿐. Temple은 신앙 노드로 별도.

**자동 검증:** 그래프 연결성·시드 재현성·도달 가능성·브랜치 쌍 배타성.

## 4. 브랜치 몬스터와 환경 (04-branch-combat)

**구현 범위:** DCSS 원본 버전별 위키·소스 검증 후 Lair 야수/히드라, Snake 나가·독·조이기, Spider 기동·독·포위, Swamp 수역·히드라·속성, Shoals 머포크·원거리·물 지형을 데이터와 AI로 구현.

**완료 조건:** 각 브랜치 1층 적응, 2층 조합, 3층 룬 수호. 새 적은 JSON과 재사용 AI를 우선하고 신규 행동은 텔레그래프 포함.

**자동 검증:** 독/조이기/지형 이동/원거리 대응·저항별 생존 차이·타일 검증.

## 5. 룬과 Zot 승리 (05-runes-zot)

**구현 범위:** 룬 브랜치 마지막 층의 수호 구역에 룬 배치, 룬 중복 획득 금지, 인벤토리와 HUD에 0/2~2/2 표기, Zot 입구에서 2개 검사.

**완료 조건:** Zot 3층, 강력한 혼합 위협, 마지막 목표를 획득해야 승리. 단순 마지막 계단으로 자동 승리하지 않는다.

**자동 검증:** 룬 없이 진입 거부, 두 룬 통과, 재진입 중복 불가, 승리 조건 테스트.

## 6. Vaults·Orc·아이템 (06-loot-branches)

**구현 범위:** Vaults 3층은 고급 장비와 위험한 혼합 전투로 빌드 완성. Orc는 상점·무리·장비 파밍 선택지. 다른 선택 브랜치는 별도 확장.

**완료 조건:** 선택 파밍은 위험/시간 비용이 있고 필수 경로만으로도 이론상 승리 가능. 선택 구역 반복 파밍 제한.

**자동 검증:** 드롭 테이블·상점·장비 강화·XP 균형·반복 왕복 악용.

## 7. 성장·신앙·저항 밸런스 (07-growth)

**구현 범위:** 24층에서 스킬·장비·신앙 권능이 후반 이전에 성숙하도록 XP와 보상 분포 재설계. 특정 저항이 유리하되 단일 저항 없다고 항상 즉사하지 않도록 대안 제공.

**완료 조건:** 브랜치 진입 자유 유지, 난도로 자연스러운 순서 유도. 낮은 클리어율 지향, 숙련자 성공 런 60분 목표.

**자동 검증:** 빌드별 XP·장비·신앙 성숙 시점, 사망 원인, 저항 의존도.

## 8. 전체 구현 후 통합 검토 (08-final-review)

**구현 범위:** 단계별 자동 테스트는 구현 과정에서 수행하되 플레이 감각·난도·구조에 대한 사용자 검토는 전 단계 통합 후 한 번에 진행.

**완료 조건:** 봇 수백 런과 모바일 실기 테스트로 60분 성공 런·낮은 승률·조작 불합리성·층별 체류시간 측정.

**자동 검증:** lint, tsc, unit, build, 통합, 시드 회귀, 모바일 UI 및 성능.
