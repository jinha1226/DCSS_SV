# 자동 스킬 훈련 + 레벨업 아이템 선택 전환 계획

2026-10-12. 기준: `main` c2cb2e959cbf7be4a48fbb1f82fdafca95fe6194. 관련: `docs/DEVELOPMENT_GUARDRAILS.md`.

> 스킬 목록, 공격 스킬 훈련 방식, 레벨업 아이템 티어는 `docs/SKILL_TRAINING.md`가 이어받았다. 겹치는 부분은 그 문서가 우선한다.

## 기획 목표와 불변 조건

- **모든 스킬은 자동 성장**한다. 킬로 얻은 유효 XP가 캐릭터 레벨과 스킬 숙련도 둘 다에 반영되며, 걷기/가만히 있기/맞기/회피 반복으로는 스킬 XP가 생기지 않는다.
- **언제나 훈련:** Fighting, Armour, Dodging, Spellcasting. 주문이 없는 미노타우로스도 Spellcasting을 조금씩 배운다. 훈련을 위한 경험치 경쟁/분배는 없다.
- **조건부 훈련:** 현재 실사용 무기 계열(마법 자동 공격 직업의 장식용 무기는 제외), 투척물 보유 시 Throwing, 실제 방패 착용 및 한손 무기일 때 Shields, 배워서 열린 마법 학파.
- **적성:** good 1.5, normal 1, bad 0.6으로 스킬 XP 성장 속도에만 반영. bad 최대 6 같은 하드 캡을 없애고 모두 27이 최대. 성장 수치는 추후 24층 밸런스 단계에서 교정.
- 스킬은 독립적으로 성장(획득 XP를 서로 빼앗지 않음). 조건부 스킬을 잠시 끄더라도 기존 레벨과 누적 XP는 보존.
- **레벨업 카드:** 스킬 대신 아이템 3가지 제시(현재 무기 계열 1개, 방어구/장신구 1개, 소모품 1개). 게임 시간은 선택 중 멈추며, 중복 레벨업은 순서대로 처리. 보상은 아이템 데이터와 기존 `generateWeapon`, `addConsumable`, 인벤토리를 이용하며 장착/사용은 플레이어가 직접 결정.
- **던전 탐험 가치 보존:** 레벨업 아이템은 일반 품질이고 고유 아티팩트는 던전 드롭 전용. 드롭 테이블과 룬, 계단 및 층별 상태는 건드리지 않는다.
- **원작 무기 특성 유지:** 도끼의 기본 광역 클리빙, 자동 기본공격과 수동 소비재/주문, 무기별 범위 유지. 범위 확장이나 무관한 시너지 추가 없음.
- 기존 8단계의 고유 보너스는 기존 2/4/6/8단계 해금 타이밍 그대로 유지한다. 대신 27단계 전체에 적용되는 매 레벨 효과의 수치만 조정한다. 고유 보너스 재설계와 고레벨 성장감 강화는 24층 밸런스 단계로 남긴다. 이는 기존 전투/주문/아이템 테스트 호환성을 위한 의도적인 선택이다.

## 핵심 데이터 설계

- `Hero.skills: Record<string, number>` 유지. 신규 `Hero.skillXp: Record<string, number>` 추가: **다음 스킬 레벨에 필요한 XP의 누적 진행분**. 스킬 도중 장비 교체 시 진행분 보존.
- `MAX_SKILL=27`, `skillXpToNext(level)=6+4*level`. 적성 배율이 반영된 XP를 각 활성 스킬에 독립적으로 더하고 여러 단계 오를 수 있음. 계산은 시드와 무관한 결정적 산술.
- Fighting의 새 레벨당 최대 HP 증가(기존 선택 직결 보너스를 자동 성장 후처리로 이동), Spellcasting의 새 레벨당 MP 증가(시작 MP=0인 캐릭터에게도 적용, 주문 습득 전에는 사용 불가). 기존 데이터 효과는 27단계에 맞춰 완만히 조정.
- `World.choosing`, `SkillChoice`, `chooseSkill`, `makeSkillChoice`는 직접 호출하는 레거시 테스트/도구 호환을 위해 남겨두되 **일반 레벨업에서는 발행하지 않는다**. 신규 `World.rewardChoices` 및 `chooseReward` 사용; `pendingChoices`는 남은 레벨업 아이템 선택 횟수.
- 신규 보상 모듈은 시뮬레이션만 담당; 기존 `makeSkillPicker` UI가 아이템 카드로 표시하고 이 모듈을 호출한다. `stepWorld`의 선택 일시정지에 신규 상태를 추가한다.

## 영향 범위/의존성

1. `src/sim/skills.ts`: XP 수입, 적성 및 자동 레벨 처리, 기존 헬퍼 보존.
2. `src/sim/rewards.ts`: 레벨업 아이템 생성/선택과 큐.
3. `src/sim/types.ts`, `src/sim/world.ts`: 신규 필드와 일시정지.
4. `src/data/json/skills.json`, `src/data/skills.ts`: Spellcasting과 27단계 성장 수치.
5. `src/ui/skillPicker.ts`, `src/ui/skillBar.ts`: 아이템 선택 카드와 스킬 UI 문구.
6. `tests/unit/skills.test.ts`, `tests/unit/rewards.test.ts`, 기존 봇: 종족 적성/성장 조건/선택 일시정지/중복 선택/아이템 지급/시드 결정성 테스트. 이전 직접 스킬 카드 헬퍼 테스트는 별도로 유지.

## 품질 기준

- 기존 `WorldOptions`, 초기 장비, 주문 해금, 보유 장비 교체와 바닥 픽업, 계단 상태, 시간정지/슈퍼핫, 경험치 불가 추적자 규칙 그대로.
- 방패 미착용·양손 무기일 때 Shields 훈련 금지. 이미 훈련한 레벨은 유지.
- 실제 자동 전투에 쓰이지 않는 마법사 시작 무기는 자동 훈련하지 않음.
- 같은 시드·같은 선택이면 보상과 스킬 결과 동일. 게임 시간이 멈춘 선택 UI에서 재선택/중복 지급 불가.
- `npm ci`, `npm run check`, `npm run build`, 모바일 화면 스모크 테스트 및 추가 단위 테스트 수행 후 머지. 환경 제한으로 못 수행한 검증은 검증 불가라고 표시.
- 최근 브랜치/룬 구현 결과를 덮어쓰지 않고 회귀 테스트로 확인.
