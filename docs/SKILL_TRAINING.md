## 1. 스킬 목록

### 기본 성장 6개 (종족 특성처럼 항상 오른다)

전투, 갑옷, 회피, 방패, 은신, 주문시전

- 킬 XP 전액을 각각 따로 받는다. 지금 `AUTOMATIC_GROWTH.md`의 방식 그대로다. 적성 배율은 적용한다.
- 방패는 지금처럼 방패를 차고 한손 무기를 들 때만 오른다.
- 주문시전은 "마법 적성"이다. 마법을 안 쓰는 캐릭터도 조금씩 오른다.
- 은신은 새로 생기는 스킬이다. 잠든 몬스터가 깨어나는 판정에 쓴다. 효과 수치는 밸런스 단계에서 정한다.

### 공격 13개 (쓴 만큼 오른다)

|---|---|---|---|
| 검 | 장검, 단검 | 화염 | |

| 창 | | 대지 | |

| 원거리 | 활·석궁·슬링, 투척 | 주술 | 주술, 공간 |
| | | 강령 | 강령, 독 |

정한 원칙은 다섯 가지다.
- **스킬은 계열만 맡고, 개성은 아이템이 가진다.** 단검의 기습, 도끼의 광역 베기, 둔기의 기절, 창의 리치는 아이템 특성이다. [원본] 무기 스킬은 명중, 피해, 공격 속도만 올리고 특수 능력은 무기 쪽에 있다.
- **원거리 무기 하나로 묶는다.** [원본] 활, 석궁, 슬링은 이미 원거리 무기 하나로 합쳐져 있다. 여기에 투척도 넣는다. 근접 캐릭터의 투척 버튼도 이 스킬을 올린다.
- **파괴술은 없앤다.** 원소가 없는 피해 마법 모음이라 정체성이 약하다. 기존 마법을 어디로 옮길지는 §5의 미정 항목에 있다.
- **강령은 따로 둔다.** 느낌이 완전히 달라서다. 언데드, 흡혈, 독, 부패를 맡고, 천천히 말려 죽이는 쪽이다.
- 발동술, 기도술, 변신술은 지금 넣지 않는다. 신이나 기물이 들어올 때 다시 정한다.

### 보조 공격은 종족 특성으로

- **[원본]** 뿔 박치기, 발굽 발차기, 꼬리치기, 송곳니 물기는 무기를 들고 있어도 근접 공격할 때 확률로 따라 나간다. 원본에서는 이 공격의 명중과 피해가 맨손 스킬로 오른다.
- **우리는 바꾼다.** 보조 공격은 종족 특성이고, 캐릭터 레벨에 따라 세진다. 맨손 스킬과는 관계없다. 기존 `headbutt_back`과 뿔 특성이 이 방식이다.
- 맨손 스킬은 무기 없이 싸우는 주 공격에만 쓴다.

## 2. 훈련 규칙: 공격 스킬은 쓴 만큼

피해량이 아니라 **행동**을 센다. 그래서 피해가 없는 보조 마법도 쓴 만큼 오른다.

**[원본]** 근접 공격은 공격할 때마다, 마법은 시전할 때마다 그 학파가 오른다. 시전은 마법 레벨에 비례하고, 여러 학파에 걸친 마법은 나눠서 오른다.

### 사용 점수

| 행동 | 점수 |
|---|---|
| 근접 휘두름 (적이 범위 안에 있을 때) | 무기 계열 +1 |
| 투척 1회, 화살 1발 | 원거리 +1 |
| 마법 시전 1회 | 마법 레벨만큼. 학파가 여러 개면 똑같이 나눈다 |

- 점수는 시간이 지나면 줄어든다. 처음 값은 반감기 30초로 하고, 밸런스 단계에서 조정한다. 그래서 최근에 싸운 방식이 반영되고, 무기를 바꾸면 XP가 자연스럽게 새 계열로 넘어간다.
- 점수는 계열별로 하나씩만 가진다. 아이템별로 따로 세지 않는다.

### 킬 XP 분배

몬스터를 잡아서 XP가 `amount`만큼 생기면 이렇게 나눈다.
1. 기본 성장 6개는 각각 `amount × 적성`을 받는다. 지금 방식과 같다.
2. 공격 스킬들은 `amount` 하나를 점수 비율대로 나눠 가진 뒤, 각자 적성을 곱한다. **여기서는 XP를 서로 나눠 가진다.** 여러 계열을 다 쓰면 그만큼 얇게 자란다.
3. 점수 합이 0이면(아무것도 안 쓰고 잡은 킬) 공격 몫은 현재 주무기 계열로 간다. 마법 자동 공격 직업이라면 가장 최근에 쓴 학파로 간다.
4. 캐릭터 레벨 XP는 지금처럼 전액 받는다.

의도는 두 가지다.
- 버프를 연타해도 XP 총량은 늘지 않는다. 비율만 바뀐다. XP는 킬에서만 나오고, 시전에는 마나가 든다.
- 높은 층은 주력 스킬에 집중해야 깰 수 있게 설계하는 걸 전제로 한다.

### 기존 조건부 훈련과의 관계

- `activeTraining`의 무기, 투척, 학파 조건은 이 점수 방식으로 바뀐다. 무기를 들고만 있거나, 투척물을 갖고만 있거나, 마법을 배우기만 해서 오르는 일은 없다.
- 이미 오른 레벨과 누적 XP는 보존한다. 비활성이어도 그대로다.

## 3. 레벨업 아이템

- **일반 아이템과 랜다트**가 나온다. 고유 아티팩트는 지금처럼 던전 드롭 전용이다.
- **티어는 현재 위치의 드롭 티어를 따른다.** 그 층에서 주울 수 있는 아이템 등급과 랜다트 확률을 레벨업 카드에도 똑같이 쓴다. [원본] 아이템 생성은 현재 깊이(absdepth)를 아이템 레벨로 쓴다.
- 지금 `depthWeights`는 3칸짜리다. 예전 3층 설계에 맞춰져 있다. 24층 구성(`IMPLEMENTATION_2RUNE.md`)에 맞춰 **위치에서 티어를 구하는 함수 하나**를 두고, 바닥 드롭과 레벨업 카드가 그 함수를 같이 쓴다.
- 무기 카드는 현재 무기 **계열**에서 나온다. 검 계열이면 장검과 단검 둘 다 나올 수 있다.

### 건너뛰기

- 세 장 다 마음에 안 들면 건너뛸 수 있고, 건너뛰면 작은 보상을 준다.
- 보상 내용은 §5의 미정 항목에 있다.

## 4. 영향 범위 (구현할 때)

1. `src/data/json/skills.json`, `src/data/skills.ts`
   - 스킬 id를 정리한다: `long_blade` → `blade`. `bow`와 `throwing`을 합쳐 `ranged`. `translocation` → `hexes`(주술).
   - `stealth`를 추가한다.
   - `conjuration`을 없애고, 남은 학파 id를 추가한다.
2. `src/data/json/species.json`: 적성 키를 19개 스킬에 맞추고, 종족 27개의 적성표를 다시 짠다. 지금의 `magic` 하나짜리 키는 학파별로 나뉜다.
3. `src/data/json/spells.json`: 파괴술 마법 7개의 학파를 바꾼다(§5).
4. `src/sim/skills.ts`: 사용 점수, 감쇠, 분배를 넣는다. `trainSkills`와 `activeTraining`을 교체한다.
5. 점수를 적립하는 곳 세 군데: 근접 휘두름(`combat.ts`), 투척과 사격, 마법 시전(`spells.ts`).
6. `src/sim/rewards.ts`, `src/sim/equipment.ts`: 위치 티어 함수, 랜다트 확률 공유, 건너뛰기.
7. UI에 레벨업 카드 건너뛰기 버튼을 넣는다.
8. 테스트
   - 휘두름, 투척, 시전이 점수를 쌓는지
   - 감쇠
   - 점수 비율대로 분배되는지
   - 점수가 0일 때
   - 기본 성장이 전액 받는지
   - 보조 마법만 써도 학파가 오르는지
   - 위치별 티어
   - 같은 시드면 결과가 같은지
   - 건너뛰기를 중복으로 받지 않는지

`DEVELOPMENT_GUARDRAILS.md`의 불변 조건(가만히 있으면 시간이 멈추는 것 등)은 그대로 지킨다.
