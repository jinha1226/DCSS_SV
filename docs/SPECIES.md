# 27종 종족 설계 목록

DCSS 0.34 계열의 플레이어 종족 27종을 참고해, 우리 게임에 필요한 고유 전투 정체성을 **새로 기술**했다.
참고: https://dcss.roguelikes.gg/wiki/Species

## 데이터 파일과 구분

- `src/data/json/species.catalog.json`: **27종 전체 설계 목록**. 현재 3종만 `playable: true`.
- `src/data/json/species.json`: **실제로 구현된 3종의 실행 데이터**. 기존 종족/직업 선택 화면은 이 파일만 읽는다.
- 미구현 24종은 의도적으로 실행 데이터에 넣지 않았다. 타일, 종족 특성 엔진, 장비 규칙이 없는데 플레이 가능한 것처럼 보이지 않도록 한 결정이다.
- `implementation: "planned"`와 `requires`는 실제로 작동하는 코드가 아니라 **앞으로 구현해야 할 시스템 목록**이다.
- `role`, `identity`, `signatureTrait`는 원작 설명을 베낀 문구나 수치가 아니라, 우리 게임용으로 새로 작성한 설계 메타데이터다.

## 추가 구현이 필요한 묶음

| 묶음 | 종족 | 주요 작업 |
| --- | --- | --- |
| 이동/지형 | 인간, 아르마타우르, 머포크, 스프리건, 텐구 | 탐험 보너스, 돌진, 물, 비행 |
| 근접/방어 | 가고일, 트롤, 오니, 나가, 옥토포드, 코볼트 | 저항, 자연공격, 붙잡기, 암습 |
| 장비 | 산악 드워프, 포미시드, 코글린 | 중갑 시전, 장비 제한/동시 장비 |
| 성장 | 놀, 드라코니언, 데몬스폰, 데미갓 | 다중 기술 성장, 변이, 신 제한 |
| 자원/언데드 | 지니, 미라, 레버넌트, 폴터가이스트, 바인 스토커 | HP 시전, 물약 제한, 흡마, 저주 연계 |
| 특수 | 펠리드 | 목숨과 부활 |

기존 구현: 미노타우로스, 바라치, 딥엘프.

이 단계에서 **종족 스탯과 적성 수치를 임의로 확정하지 않았다**. 24종을 실제 구현하는 시점에 `species.json`에 능력치와 타일을 정의하고 테스트한다.
