# 작업 지시: 4단계 성장

먼저 `docs/CODEX_PROMPT.md`의 2절(어기면 안 되는 것)과 7절(코드 지도)을 읽어라. 이 문서는 4단계만 다룬다. 5단계는 시작하기 전에 사용자에게 묻는다.

**목표**: 적을 쓰러뜨려 경험치를 얻고, 레벨이 오르면 화면이 멈추고 스킬 카드 셋 중 하나를 고른다. 폰에서 답할 질문은 "카드를 골랐을 때 달라진 게 느껴지는가", "카드가 한눈에 읽히는가"다.

## 사용자가 확정한 것 (바꾸지 마라)

스킬은 세 갈래다.

- **공통 스킬** (전투, 갑옷, 방패, 회피): 어느 캐릭터가 골라도 같은 효과다. 효과에 종족이나 무기 이름이 들어가면 안 된다. 뒤에 올 궁수와 마법사도 같은 카드를 쓴다.
- **무기 스킬** (도끼, 투척): 그 무기를 쓸 때만 뜻이 있다.
- **종족 특성** (미노타우로스의 뿔 받기): 카드로 오르지 않는다. 원본처럼 **캐릭터 레벨이 오르면 저절로 세진다.**

카드 한 장이 스킬 1단계다. 스킬은 8단계까지. 매 단계 숫자가 오르고, 2·4·6·8단계에는 싸우는 모습이 바뀐다.

| 스킬 | 매 단계 | 2단계 | 4단계 | 6단계 | 8단계 |
| --- | --- | --- | --- | --- | --- |
| 도끼 | 피해 +1 | 베는 범위가 넓어진다 | 세 번째 휘두름은 크게 돈다 | 맞은 적이 잠깐 멈칫한다 | 쓰러뜨리면 바로 또 휘두른다 |
| 전투 | 최대 체력 +8 | 체력이 두 배 빨리 찬다 | 쓰러뜨릴 때마다 체력 +1 | 체력이 낮으면 더 세게 친다 | 죽을 피해를 층마다 한 번 버틴다 |
| 갑옷 | 받는 피해 -1 | 돌 피해가 절반 | 약한 타격은 튕겨 낸다 | 떼 속에서도 안 느려진다 | 때린 적이 되받아 다친다 |
| 방패 | 막을 확률 +4% | 막으면 그 적을 밀쳐 낸다 | 날아오는 건 두 배로 잘 막는다 | 막힌 적이 잠깐 멍해진다 | 막은 직후 기본 공격이 바로 나간다 |
| 회피 | 피할 확률 +3% | 걸음이 조금 빨라진다 | 피하면 그 적이 헛쳐서 다음 공격이 늦어진다 | 떼 사이를 덜 막히고 지난다 | 한 번 피하면 잠깐 동안 전부 피한다 |
| 투척 | 피해 +1, 재사용 조금 짧게 | 맞은 적을 뚫고 하나 더 | 한 번에 둘을 던진다 | 맞은 적이 느려진다 | 돌아오면서 한 번 더 때린다 |

미노타우로스의 적성: **도끼와 전투는 첫 카드에 2단계로 시작한다.**

이 표의 글귀가 곧 카드에 적히는 한 줄이다. 더 길게 풀어 쓰지 마라.

## 규칙의 세부 (숫자는 시작값이다. `src/data`에 두고 6단계에서 맞춘다)

**경험치와 레벨**

- 몬스터마다 경험치: 쥐 1, 박쥐 2, 자칼 2, 고블린 3, 코볼트 3, 독사 3, 놀 5, 오우거 15. `MonsterStats`에 더한다.
- 다음 레벨까지 `6 + 4 × (레벨 − 1)`. 층 셋을 도는 한 판에 레벨업이 열 번 남짓 나오게 봇으로 확인하고 맞춘다.
- 레벨이 오르면 세계가 멈춘다(`w.choosing`에 카드 셋). 고르기 전에는 `stepWorld`가 아무것도 움직이지 않는다. `chooseSkill(w, id)`로 고르면 다시 흐른다. 한 번에 두 레벨이 오르면 고르기가 두 번 이어진다(선택이 사라지면 안 된다).
- 카드는 8단계가 아닌 스킬 중에서 서로 다른 셋을 `w.rng`로 뽑는다. 남은 스킬이 셋보다 적으면 있는 만큼만.
- 층을 내려가도 레벨과 스킬은 남는다.

**맞을 때의 순서** (근접 타격과 돌 모두 `hurtHero`로 모인다. 여기에 넣는다)

1. 회피: 확률로 통째로 피한다. 피해도 독도 없다.
2. 방패: 확률로 통째로 막는다. 피해도 독도 없다.
3. 갑옷: 피해에서 단계만큼 뺀다. 최소 1.

확률은 `w.rng`로 굴린다(같은 씨앗이면 같은 판). 피하면 `dodge`, 막으면 `block` 이벤트를 내고, 화면은 "피함", "막음"을 작은 글씨로 띄운다. 번쩍이는 효과는 넣지 않는다.

**단계 효과의 정의**

| 스킬 | 정의 |
| --- | --- |
| 도끼 2 | 닿는 거리 +0.3칸 |
| 도끼 4 | 세 번째 휘두름마다 닿는 거리 1.5배, 피해 1.5배. 궤적도 크게 그린다 |
| 도끼 6 | 맞은 적이 0.25초 멈춘다(`stun`) |
| 도끼 8 | 적을 쓰러뜨린 휘두름은 재사용 대기가 없다 |
| 전투 매 단계 | 최대 체력 +8, 그만큼 바로 회복 |
| 전투 2 | 저절로 차는 속도 두 배 |
| 전투 4 | 쓰러뜨릴 때마다 체력 +1 |
| 전투 6 | 체력이 30% 이하면 주는 피해 1.3배 |
| 전투 8 | 층마다 한 번, 죽을 피해를 받으면 체력 1로 남고 1초 동안 피해를 받지 않는다 |
| 갑옷 2 | 돌 피해를 먼저 절반으로 (그다음에 갑옷 단계만큼 뺀다) |
| 갑옷 4 | 깎기 전 피해가 3 이하인 타격은 피해가 없다 |
| 갑옷 6 | 몬스터와 몸이 부딪혀도 밀리지 않는다(`HERO.give` → 0) |
| 갑옷 8 | 타격이 들어오면 때린 적이 2 다친다 |
| 방패 매 단계 | 막을 확률 +4% (8단계에 32%) |
| 방패 2 | 막힌 적이 뒤로 밀린다 |
| 방패 4 | 돌은 막을 확률 두 배 |
| 방패 6 | 막힌 적이 0.6초 멍해진다 |
| 방패 8 | 막으면 도끼의 재사용 대기가 0이 된다. 코드는 "기본 공격"으로 일반화해 둔다 |
| 회피 매 단계 | 피할 확률 +3% (8단계에 24%) |
| 회피 2 | 걷는 속도 +6% |
| 회피 4 | 피한 타격의 주인은 다음 공격까지 0.8초 더 쉰다 |
| 회피 6 | 몬스터와 부딪혀 밀리는 양이 절반. 갑옷 6이 있으면 0 그대로 |
| 회피 8 | 한 번 피하면 0.8초 동안 모든 타격을 피한다 |
| 투척 매 단계 | 피해 +1, 재사용 −0.07초 |
| 투척 2 | 첫 적을 뚫고 다음 적 하나까지 맞힌다 |
| 투척 4 | 한 번에 둘을 던진다. `throwTarget`의 순서로 첫째와 둘째를 노린다 |
| 투척 6 | 맞은 적이 2초 동안 40% 느려진다 |
| 투척 8 | 끝까지 날아간 뒤 영웅에게 돌아오며, 돌아오는 길에 닿는 적도 맞힌다 |

**종족 특성**: 뿔 받기는 캐릭터 레벨 2마다 피해 +1, 레벨 3마다 주기 −0.1초(1.5초까지).

## 화면

- **카드 화면**: 세계가 멈추면 카드 셋이 세로로 뜬다. 카드 한 장에 스킬 이름, `2 → 3단계`, 한 줄. 2·4·6·8단계로 가는 카드에는 위 표의 그 칸 글귀를, 그 밖의 카드에는 "매 단계" 칸 글귀를 적는다. 누르기 쉽게 크게(높이 72px 이상). 스틱을 쥔 채 레벨이 올라도 실수로 고르지 않게, 뜨고 0.4초 동안은 눌리지 않는다.
- **화면 위**: 레벨과 경험치 막대를 체력 막대 아래에 얇게. 지금 가진 스킬과 단계는 카드 화면 아래쪽에 한 줄로 보여 준다(싸우는 화면에는 두지 않는다. 좁다).
- 끝 화면에 레벨과 고른 스킬을 적는다.

## 테스트와 재기

- 스킬 단계 효과마다 테스트 하나씩(위 정의 표의 줄마다). 맞을 때의 순서, 두 레벨이 한 번에 오를 때, 카드가 겹치지 않는 것, 8단계 스킬이 안 나오는 것, 고르기 전에 세계가 멈추는 것, 층을 내려가도 남는 것, 미노타우로스의 첫 카드 2단계.
- 봇(`tests/bench/bots.ts`)이 카드를 고르게 한다. 고르는 법을 바꿔 끼울 수 있게 해서 **"도끼만 올리는 판"과 "방어(갑옷·방패·회피)만 올리는 판"**을 서른 판씩 돌린다. 둘의 결과(도달 층, 버틴 시간, 처치 수)가 다르게 나와야 한다. 숫자를 `docs/PLAN.md`의 4단계에 표로 적는다. 난이도 자체는 6단계에서 맞추므로, 여기서는 차이가 나는지만 본다.

## 끝났다는 기준

- `npm run check`와 `npx vite build` 통과, main에 커밋 하나로 올리고 Actions 성공 확인.
- 한 판에 레벨업이 열 번 남짓.
- 폰 크기(390×844, 터치)로 띄워 카드 화면이 읽히고 눌리는지 직접 본다.
- `docs/PLAN.md`: 3단계 체크, 4단계의 스킬 표를 이 문서의 표로 바꾸고, 정한 것과 봇 숫자를 적는다. `README.md`에 바뀐 것이 있으면 고친다.
- 사용자에게 알린다: 무엇이 들어갔는지, 봇 숫자, **폰에서 볼 것**(카드를 골랐을 때 달라진 게 느껴지는가, 카드가 한눈에 읽히는가, 레벨업이 너무 잦거나 드물지 않은가).
